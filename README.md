# Carson Kipkalya — Personal Site

Personal website and home base for Carson Kipkalya.

## Project

This site is a simple, evolving personal website built around three things:

- software projects and experiments
- writing and ideas
- a small, secondary freelance practice focused on websites and landing pages

The site is intentionally lightweight rather than a large portfolio system. It's a place to show what I'm building and what I'm thinking about — not necessarily how they fit together yet.

## Built With

- Astro
- TypeScript
- Plain CSS
- Local content collections
- Native HTML interactions
- Netlify for deployment

The site takes a static-first approach, keeping the implementation simple and only adding small interactive pieces where they're worth the complexity.

## Current Features

- Responsive layout across mobile, tablet, and desktop
- Accessible semantic structure and keyboard-friendly interactions
- Expandable project content
- Expandable writing and notes
- Project content managed through Astro content collections
- Consistent custom typography and visual styling
- Fixed, responsive navigation
- Reduced-motion considerations for interactive elements
- Myston (Em), a small interactive robot companion on larger screens

## Development

Install dependencies:

\`\`\`bash
npm install
\`\`\`

Start the development server:

\`\`\`bash
npm run dev
\`\`\`

Build for production:

\`\`\`bash
npm run build
\`\`\`

The site is a working V1 and will keep changing as I build projects, publish writing, and learn from using it in the real world.
